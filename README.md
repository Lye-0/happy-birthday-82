# 82 WISHES
## 82の灯り、ひとつの願い。

82歳の誕生日を祝う、フルーツケーキの3Dインタラクティブ作品です。
白いクリーム、苺、ブルーベリー、ラズベリー、キウイ、ミントと、**82本のろうそく**を囲んで、ひと息でお祝いします。

## 使い方

ZIPを展開して、`82-wishes/index.html` を通常のWebブラウザで開いてください。HTML・CSS・JavaScriptは別ファイルです。フォルダ内の位置関係を保ってください。

この作品はCDN、画像配信、外部フォント、APIに依存しません。ケーキの形状、フルーツの表面、炎、音まで、その場で生成します。マイクやカメラの許可も不要です。

ファイルの内容を表示するだけのプレビューアでは、JavaScriptや3Dが動かない場合があります。その場合は、以下のローカルサーバーか静的ホスティングで開いてください。

### ローカルサーバーで開く

Node.js 18以上が利用できる環境で、このフォルダをターミナルで開いて実行します。依存パッケージのインストールは不要です。

```sh
npm start
```

表示された `http://localhost:5173` をブラウザで開きます。ポートが使用中の場合は、例えば次のように変更できます。

```sh
npm start -- 5174
```

サーバーは自分のPCだけに接続できる `127.0.0.1` にバインドします。スマホから鑑賞する際は、フォルダ全体を静的ホスティングに配置したURLを使用してください。ビルドは不要です。

## 操作

| 操作 | 動作 |
| --- | --- |
| 「願いを込めて、吹き消す」 | 今見ている側から息が広がり、82本の炎が順番に消える |
| 「もう一度、灯す」 | ろうそくを増やさず、同じ82本を再点火する |
| 左・中・右ボタンでドラッグ | ケーキの周囲を回り込んで眺める |
| スマホで1本指ドラッグ | 視点を回転する |
| ホイール／2本指のピンチ | 拡大・縮小する |
| 「上から」 | 上空から盛り付けを眺める |
| 「82本の配置を見る」 | 上からの視点と、30・24・18・10本の確認表示を開く |
| 「視点を戻す」 | 最初の構図に戻り、本数確認表示を閉じる |
| 右上の音ボタン | 息の音と、消火後の小さなベルの音をオン／オフにする |
| 右上の設定ボタン | 画質・自動回転・一時停止・音量を変更する |
| `Space` | 吹き消す／再点火する |
| `R` | 再点火する |
| `V` | 上からの視点を切り替える |
| `Escape` | 設定を閉じる。設定が閉じているときは視点を戻す |

キーボードのショートカットは設定画面や入力欄の操作中には発火しません。ボタンにフォーカスがあるときのSpaceは、そのボタン本来の動作になります。

**音は初期オフ、描画品質はスマホも含めて「標準」です。** 動きが重い場合は、設定から「軽量」を選んでください。消火ボタンは一時停止中でも演出を再開します。OSの「視差効果を減らす」等の設定を検出した場合は、紙吹雪とUIの移動アニメーションを抑えます。炎を含む動き全体を止めるには、作品内の一時停止を使用してください。

## 82本であること

数字型のろうそくで代用していません。細長いろうそくの3Dインスタンスを、以下の4つの同心円に配置しています。

| 外側から | ろうそく |
| --- | ---: |
| 第1周 | 30本 |
| 第2周 | 24本 |
| 第3周 | 18本 |
| 第4周 | 10本 |
| **合計** | **82本** |

`src/core.js` の `CANDLE_COUNT` と `RINGS` が生成の基準です。ろうそくのIDは1〜82。芯も82個、炎の発生位置も82個です。中央の小さな「82」はチョコレートの飾りで、ろうそくではありません。

画面の数値は、消火状態から算出した実際の点灯数です。全消火後は `0 / 82`、再点火すると `82 / 82` に戻ります。繰り返してもろうそくの3Dモデルは増えません。

## 演出と構成

生クリームの細かな塗り跡、絞りクリーム、苺の種、ブルーベリーの白い果粉、キウイの種と果肉を、形状と手続き的な表面表現で作成しています。背景は暗いテーブルと柔らかいスタジオ照明です。

炎は個別に揺らぎ、息が届くと傾いて縮みます。消えた後は芯の赤い余熱が冷め、細い煙が立ちのぼります。全消火をきっかけに、お祝いのメッセージと控えめな紙吹雪が現れます。演出のために調整したシミュレーションであり、燃焼や流体を厳密に計算する物理モデルではありません。

```text
82-wishes/
├── index.html                 画面・アクセシビリティ用の文言
├── css/
│   └── style.css              配色・レスポンシブレイアウト・UI演出
├── src/
│   ├── core.js                82本の配置・消火状態・時間進行
│   ├── math.js                カメラ・行列・色の計算
│   ├── geometry.js            ケーキや果物のメッシュ生成
│   ├── renderer.js            WebGL2・照明・影・炎・煙・ブルーム
│   ├── cake.js                盛り付け・材質・ろうそくの組み立て
│   ├── audio.js               息と小さなベルの音の合成
│   └── app.js                 入力・カメラ・UI・描画ループ
├── scripts/
│   ├── serve.mjs              依存パッケージ不要のローカルサーバー
│   └── build-preview.mjs      チャット用の単体プレビューを生成
├── tests/                     Node.jsの標準機能で実行するテスト
├── TESTING.md                 確認結果と未検証の範囲
└── package.json
```

開発にはWebGL2を直接使用しています。Three.jsなどの外部エンジン、npm依存パッケージ、外部素材、ダウンロード用のフォントファイルは含めていません。

## テストとプレビュー生成

```sh
npm test
npm run preview:build
```

`preview:build` は、分離した実装から同じ内容をインライン化した `82-WISHES-preview.html` を生成します。これはチャットで作品を開きやすくするための補助出力です。配布ZIPの本体は、上の分離構成のままです。

開発者ツールで `window.__WISHES__.inspect()` を実行すると、実際に生成したモデル・芯・炎の発生位置・点灯数などを確認できます。`?capture=1` は自動フレームを止めて撮影用に手動進行するモードです。通常の鑑賞では付けないでください。

## 動作環境について

JavaScriptとWebGL2が必要です。3Dが利用できない場合は、説明と再試行ボタンを表示します。SafariやiPhone実機での確認は行っていません。実施したChromium描画・操作検証の内容と、その範囲は `TESTING.md` に記載しています。
